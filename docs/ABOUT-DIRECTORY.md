# About and Coach Directory Pro

The local About page explains the independent MUSCLIVO LIVE vision, free launch plan, feature navigation, privacy and consent, policy links and development status. No fabricated team members, testimonials, credentials or contacts are displayed. Public deployment remains gated.

The coach directory starts with the active interface language, supports inclusive multi-language selection or all languages, and filters by search (name, city, sport, biography or level), with a verified-only option. Verified coaches sort first, and each expandable card shows the public profile details, languages, chat/report actions and a consent-based coaching invitation for eligible personal members. Verification is a platform status, not a certification of competence. Existing coaching management, acceptance, program assignment and progress permissions remain unchanged.

The directory uses the existing authenticated privacy-filtered state, never private emails or unrelated data. Private/blocked profiles are excluded on the server. Search preferences are session-only and account-specific. No external services, new dependencies, or changes to production activation are needed. Arabic, English and Swedish are maintained in their respective translation files.
